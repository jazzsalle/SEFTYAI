### 포함 판정 규칙 제안

1. **숫자 정규화** — 응답에서 천 단위 쉼표 제거(`172,605` → `172605`), 단위 붙은 수(`9,758명`, `0.891㎢`)는 수만 뽑는다. 정답 단위가 원(`property_damage: 318230900000.0`)인데 응답은 «3,182억» 처럼 쓰는 경우가 있어 금액은 `auto` 에서 뺐다(사람 확인).
2. **소수** — 소수 둘째 자리까지 반올림 일치 허용(예 `8.274` ↔ `8.27`). 416 채점도 이 정도 차를 일치로 봤다.
3. **근사 허용 없음(자동)** — 416 채점은 «1,872 vs 1,875 (3 차)» 를 정답으로 봤지만, 자동 표시는 정확 일치만 «포함»으로 하고 차이는 사람이 본다.
4. **이름** — 지명·시설명은 부분 문자열 포함(«성주4지구»). 원문 정답의 잘린 이름(`화암10지구(지방도421`)도 그대로 부분 일치로 쓴다.
5. **범위 주의** — `scope_note` 가 있는 12개는 질문 범위(전국·시도)가 조건의 기준지역보다 넓다. 416 의 부분 정답 상당수가 «조건으로 범위를 좁힌» 경우였으므로(원문 §4 패턴 1), 리포트에 이 표시를 같이 띄운다.
6. **이어서 묻기** — `follow_up` 6개(A-14-g2 · A-26-v2 · D-01-v2 · P09-02-g2 · P09-03-v2 · P09-04-g2)는 앞 변형과 같은 `conversation_id` 로 다음 턴에 보내야 질문이 성립한다.
