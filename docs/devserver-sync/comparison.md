### 1차에서 개발서버와 다르게 둔 것 (결정 대기)
- 일부 제공(PARTIAL_SUCCESS) 답: 개발서버는 실패 문구만, SEFTYAI는 답 글 + 「일부 제공」 표시 유지
- 브리핑 카드 첫 문단 미리보기·더보기 접기: 넣지 않음
- 특보 상세 창의 전국 집계 건수 칩·종류별 구역 수 막대(경보 빨강): 앱이 센 값·차트 빨강이라 넣지 않음
- 상태 이력: 개발서버는 getPwnCd를 DB에 쌓아 씀, SEFTYAI는 통보문의 해당구역·발효시각 줄로 만듦
- 해상 특보: 이름에 「(해상)」을 붙이지 않고 옆에 작은 「해상」 표지
- 특보 띠 5초 자동 넘김: 옮기지 않음
