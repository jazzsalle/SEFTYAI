- 글자 크기: 우리 화면은 글자 크기를 px 토큰(--fs-*)으로 적어, 루트 % 와 함께 토큰도 같은 비율로 키운다. 토큰 없이 px 를 바로 적은 곳은 커지지 않는다(개발서버는 전부 rem 이라 루트 하나로 끝남). 저장 이름 `sa.font-scale`, 예전 `sa.font`(작게·보통·크게·아주 크게)는 작게·보통·조금 크게·크게로 잇는다
- 질문 칸 딱지: 기준시각(우리 기능) 딱지에도 × 를 단다(지정했을 때만). 상황 상세정보 × 는 특보 종류·단계·키워드·측정값을 함께 지운다(개발서버 detailCount 와 같은 범위)
- 다시 연 대화: 개발서버는 저장된 대화를 다시 불러온 턴인지 안다. 우리는 대화가 작업을 가리켜, **이 화면을 열기 전에 끝난 실패**를 다시 연 대화의 턴으로 본다(새로 고침 뒤 보이는 지난 실패도 같은 문구)
- 지도 타일: 개발서버처럼 로그인을 묻지 않는다(<img> 로 가져가 머리글을 못 붙임 · 공개 배경지도). 행정경계 WMS 도 같은 길로(개발서버는 경계를 데이터 API 로 받음 — 우리는 WMS 유지). 키가 없거나 VWorld 가 거절하면 404 → 화면이 오류 수를 세어 OSM·경계 없음으로 물러선다(전에는 키가 없으면 처음부터 OSM). 실제 VWorld 응답(서버에서 등록 주소 Referer 로 부름)은 배포 뒤 확인 필요

### 예전 결정과 부딪히던 넷(2026-11-07, R57)에서 개발서버와 다르게 둔 것
- 질문 칸 잠금은 **지금 보는 대화**의 턴으로 센다(개발서버도 useConversation turns — 같은 대화). 브리핑 세트는 우리가 대화 안 묶음으로 두므로 그 대화의 묶음 턴이 하나라도 돌면 막는다(개발서버는 화면의 브리핑 상태). 작업 상태를 아직 받지 못한 턴(다시 연 대화의 옛 작업)은 돌지 않는 것으로 본다. 서버의 계정 4·전체 8 한도와 대기열(R8)은 그대로 — 화면이 막아도 다른 창·다른 PC 질문은 서버가 줄 세운다
- AI 모드 창의 [브리핑 시작]·브리핑 타일은 막지 않는다(개발서버도 막지 않음 — 개발서버는 넷이 차면 ask 가 말없이 버림, 우리는 서버 대기열로)
- 남은 시간은 서버의 실제 끝나는 시각을 센다. 개발서버는 새로 고침(조용한 재발급) 뒤 토큰 수명 240분을 다시 보여 주지만 서버는 로그인·연장 때부터 세어, 새로 고친 화면의 시계가 실제보다 길게 보인다 — 우리는 새로 고쳐도 같은 시각
- 끝나는 순간: 개발서버는 5초 두드림이 듣는다. 우리는 두드림이 20초(R53)라 0 이 되는 그 순간 따로 한 번 묻는다. 끝난 접속은 지우지 않고 그대로 둔다(만료 시각으로 가림 — 개발서버는 행을 지움). 브라우저를 닫았다 열어도 쿠키(240분)가 살아 있으면 이어진다(개발서버는 탭 표식이 없으면 로그인 화면부터)
- [시간 연장]을 거듭 누르면 끝이 없다(개발서버와 같음 — 예전 절대 12시간은 없앰). 「로그아웃까지 남은 시간」은 사용자 메뉴를 열어야 보인다(개발서버와 같음)
- 작업 8분: 넘기면 T3Q 에 취소를 보낸다(개발서버는 표시만 바꾸고 상류를 두어 T3Q 가 계속 돈다 — 단일 파드 부하, R1). 8분을 넘겨도 T3Q 에 먼저 물어 이미 끝난 답은 받는다(R22 — 개발서버는 묻기 전에 끊음). 결과 보관 24시간(ResultRetentionHours)은 따르지 않는다 — 개발서버는 작업 표가 메모리이고 답은 대화 기록 표에 따로 남지만, 우리 작업 행(sa_agent_jobs)이 대화 이력·보고서가 읽는 답 원본이라 지우면 지난 대화가 빈다
- 누리집 띠: 개발서버 비밀번호 변경 「화면」에도 띠가 있으나 우리 첫 로그인 비밀번호 변경은 창(PasswordModal)이라 띠를 얹을 화면이 없다. 안쪽 화면(통합 탐색·대화 이력 등)은 개발서버처럼 띠 없이 한 줄 머리말
