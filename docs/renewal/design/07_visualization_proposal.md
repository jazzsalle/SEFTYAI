# 시각화 제안 (승인 요청 — 지시 19) · 2026-10-28

> **경과(2026-10-28)** — V1~V4 부분 승인 → 적용 전후 비교 결과 **V1 반려**(큰 점수 막대·영어 열 이름). 방향: 재난 담당자가 핵심을 한눈에 보는 독자 구성, 한국어 표기, 빨강 미사용. V2~V4 는 임시 적용 상태이며 최종 시각화는 디자이너 에이전트 설계(`08_visual/`) 검토·승인 뒤 적용한다(R20).

> **결론** — 에이전트 답(T3Q-01)은 시각화하지 않는다. 구조칸(`entities`·`result_groups`·`follow_up_questions`)이 실측 37/37건 모두 비어 있고, 답 글의 표는 답마다 열·제목이 달라(첫 제목만 11가지) 일관된 속성이 없다. 답 글의 표를 읽어 그래프로 바꾸는 것은 응답 재가공이므로 하지 않는다.
> 대신 **같은 요청이면 같은 결과를 주는 Data API 응답**(필드가 고정)에 한해 아래 시각화를 제안한다. 모두 "자동 조회 데이터"·상세 패널 안에서만 쓰고, 표(원값)를 항상 함께 둔다.
