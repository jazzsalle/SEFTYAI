## 0. 설계 원칙

1. **쪽 번호 근거는 사건(재해연보)에만 있다**(A §6, C §7). 그래서 오후 장면 S4~S6은 이름·날짜로 정한 사건을 축으로 잡았다. 사건 5개의 쪽은 모두 T3Q-19로 확인했다(2장 표).
2. **위험지구·시설은 이름으로 정해서 묻는다**(B 규칙 2). 근거는 「원천 표·행」과 계획 ID다(T3Q-15 `basis`). 개선지구 사업 내용을 이름으로 물은 모양(B-19)은 답 글에도 «중기정비계획 총괄조서»가 나왔다(65초, 2회).
3. **근거는 답 글이 아니라 자동 조회로 먼저 보인다.** 녹화 121문 가운데 답 글에 쪽을 인용한 것은 0문, 문서명이 나온 것은 5문이다(B §2). 질문을 누르면 1초 안에 Data API 표가 뜬다. 행을 누르면 상세(원천 표·행)가 나오고, 사건 행을 누르면 사건 상세(타임라인·피해, 재해연보 쪽)가 나온다.
4. **답 글에 문서명이 나왔던 두 모양을 그대로 쓴다.** S2는 «이름으로 정한 지구의 사업 내용»(B-19), S4는 «사건을 열어줘»(D-01, 답 출처 줄에 «2024_재해연보»)다. 예비 3문(BS-4b·IJ-4b·YC-4b)은 «근거 문서와 쪽 번호까지»를 질문에 넣었다. 답 글에 쪽이 나오는지 시험하는 질문이고, 정답 쪽은 이미 안다.
5. **조건 입력은 두 갈래다**(3장).
   - 자동 조회 결과를 실제로 바꾸는 조건: 발생기간 + 키워드.
   - 답의 전제를 고정하는 조건: 특보 + 1시간 강우.
   - 값은 고정 프리셋으로 둔다. 재사용 열쇠가 늘 같게(D §3).
6. **넣지 않은 것**
   - 실시간 수위·CCTV·예측·대피소 안내. 질문 글에 «지금·현재·예상»도 쓰지 않는다.
   - 행동매뉴얼 질의(QQ-03). 원천이 없어 «정보 부족»(`manual NOT_IN_SOURCE`)이 오고, 녹화 3건 가운데 2건은 실시간 예보·수위까지 섞었다(C §9).
   - 매뉴얼 쪽은 앱 대응절차(지자체 매뉴얼 원문 쪽, **T3Q 아님**)로 따로 보인다.

공통
- **질문 출처**는 모두 **SUGGEST**다. 시연 탭이나 질문 모음에서 누르는 길이고(D §1.2), 예열도 SUGGEST로 한다.
- **지역 조건**은 계정 기본값이다.
  - 부산: `{2600000000, 부산광역시, SIDO}`
  - 인제: `{5181000000, 강원특별자치도 인제군, SIGUNGU}`
  - 영천: `{4723000000, 경상북도 영천시, SIGUNGU}`
- 「대조값」은 Data API 실측값이다. «녹화 답»이라고 적은 것은 에이전트 답 값이라 Data API로 대조할 수 없다.
- 「원형」은 T3Q 역량질문 변형이다. 괄호 안은 Agent 416 판정과 처리 시간이다.

### 4.2 인제 — 산사태·계곡 재해(산사태·급경사지·캠핑·야영장 주변 과거 피해사례 · 당시 통제·대피 조치)

4. 공간 질문 4개(BS-8·IJ-8·IJ-8b·YC-8b)는 지역 원천 도형(부산 도시침수지도·지하층, 인제 하천구역, 영천 소하천구역)이 있는지 T3Q에 확인한다.

## 7. 요약

- **규모**: 주 질문 24개(지역마다 8, 장면 S1~S8)와 예비 24개로 모두 48문이다. 출처는 모두 SUGGEST다.
- **조건 입력 질의**: 주 질문 12개(부산 4 · 인제 3 · 영천 5), 예비까지 23개다. 두 갈래다.
  - 발생기간+키워드: 자동 조회 유사재난 목록에서 그 사건을 5·5·14·3·9위로 올린다(이 단계 실측, 0.3초).
  - 호우경보+1시간 강우: 지자체 매뉴얼 기준값(부산 30mm p.119 · 인제 20mm p.58 · 영천 100mm p.289)으로 답의 전제를 고정한다.
- **근거**
  - 재해연보 쪽(◎): 9문. 2020 p.153 · 2023 p.148 · 2022 p.146 · 2024 p.154를 T3Q-19로 확인했다.
  - 원천 표·행(○): 13문. 총괄조서 51·564·2242행, 중기계획 202행, 지하차도 현황 275·995행 등이다.
  - 근거 없음: 2문(반지하 공간 질문 BS-8, 2026 문자 IJ-6).
- **자신 있는 점**
  - 근거는 답 글이 아니라 자동 조회 → 행·사건 클릭으로 0.3~2초 안에 나온다. 그래서 답을 기다리는 2분 동안에도 근거를 보일 수 있다.
  - 같은 모양을 두 번 이상 잰 질문은 생방송 후보다: BS-1b·IJ-1(65~75초), S2 지구 이름 꼴(65초 2회), 특보 꼴 BS-7b·YC-7b(95~96초), YC-5(85·95초).
  - 대조값은 Data API로 확인했다(지하차도 22곳, D·E 급경사지 7·17·2, 토석류 249, 소하천 지구 4, 2023-09-16 부산 대피·통제 문자 10건 등).
- **위험**
  - 재해연보 쪽은 D⑤ 승인 전에는 화면에 뜨지 않는다.
  - 사건 열기·침수흔적·두 원천 겹치기·공간 질문(S4·S5·S8)은 126~216초 꼴이라 예열해야 한다.
  - 인제 «당시 통제·대피 조치»는 T3Q 원천에 없어 2026년 문자로 대신했다. 예비 IJ-6b는 «없음» 답이 예상된다.
  - 공간 질문 4개는 지역 자료가 있는지 아직 모른다.
  - 강우 조건과 근거 요청이 처리 시간에 주는 영향은 이번 시험에서 처음 잰다.
