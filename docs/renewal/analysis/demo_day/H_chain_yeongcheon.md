가장 좋은 흐름(5단계): **YC-01 → YC-02 → YC-03 → YC-04 → YC-08**. 시간 여유가 있으면 YC-04 뒤에 YC-06(당시 특보)을 넣는다. 질문은 모두 앞 답의 읍면·지구·저수지·리·사건 이름을 넣은 독립 문장이라 질문 모음에 넣어 예열할 수 있다. 다만 하네스는 질문 출처 USER 로 보냈다. 앱 질문 모음 경로(SUGGEST)와는 재사용 열쇠가 다르므로 앱 경로로 다시 받아 두어야 한다(D 문서 §1.3).

자동 조회 데이터(참고 — 이번 사슬에서 재지 않음, A·C 문서 실측): 기준지역 영천시·호우이면 위험지역 644건(첫 50건: 급경사지 20·개선지구 16·홍수취약 6·붕괴위험 5·풍수해 3)과 취약시설 22건(재해위험저수지 20·지하차도 2)이 1초 안팎에 먼저 뜬다. **침수흔적은 «결과 없음»**으로 뜬다. 유사사례는 영천·태풍 조건에서 힌남노가 1위가 아니다(C §4 ※). YC-03 처럼 기준지역을 북안면으로 좁히면 목록도 북안면으로 좁혀진다(건수는 재지 않음).

## 5. 주의 — 답끼리 어긋난 곳 · 원천 확인이 필요한 서술

화면에는 응답을 가공하지 않고 그대로 보이므로, 아래 줄들도 그대로 보인다. 시연 해설에서 공식 자료처럼 말하지 않는다.

1. **오산 지구 위치**: YC-01 은 «화북면 오산리 일원», YC-02 는 «오산 지구(북안면 오산리 자연재해위험개선지구)»라고 썼다. 같은 에이전트의 답끼리 어긋난다.
2. **금곡2지 우선순위**: YC-02 는 «1순위 (최우선)»으로 꼽았다(사업 현황 «국비사업완료»). YC-03 은 «2020-01-07 정비 후 해제»라고 썼다. 시연에서는 ② 장면의 «좁히니 바로잡힌다»로 쓸 수 있다.
3. **원곡천 구분**: YC-07 은 «원곡천(소하천)», YC-07b 는 «원곡천 (지방하천)». A 문서 원천(북안명주 시설명 «북안천, 원곡천 등», 시설등급 «지방하천, 소하천, 세천»)으로는 가를 수 없다.
4. **수계 판단**: YC-07 의 «상리는 원곡천 상류 수계», «용계리 등은 독립 지류»는 출처 표기가 없는 에이전트 추론이다. 현장 확인이 필요하다.
5. **결론 문장**: YC-07 «북안명주 사업 대상 밖» ↔ YC-07b «원곡천·북안천 일원 종합정비계획과 연계되어 관리». 예열 뒤 같은 답을 재사용해야 시연 중 결론이 바뀌지 않는다.
6. **대평지 지정일·EAP**: YC-08 의 «2023년 1월 9일 재해위험저수지로 지정», «2023년 8월 21일 비상대처계획(EAP)»은 이번에 데이터 API 로 대조하지 않았다(A 재고에 대평지 상세 없음).
7. **권고·착안사항**: YC-02 §3, YC-03 조치 사항, YC-07 §4, YC-08 제언은 출처가 없는 에이전트 서술이다(대피 권고·신규 지정 건의 등). 근거 문서에서 나온 것이 아니다.
8. **지도 이름표**: YC-08 refs 4개는 표시 이름이 모두 «영천시»다. YC-01 r4 는 북안명주(풍수해생활권)를 «자연재해위험개선지구»로 표시했다. YC-05·YC-06 은 refs 0 이라 지도에 아무것도 찍히지 않는다.
9. `context_used` 는 9문 모두 빈 값이다. 조건이 쓰였는지는 답 글(YC-02·YC-03 첫 문장)로만 알 수 있다.

## 7. 요약

영천 사슬은 9회(한도 9회 모두 사용)를 보내 8단계 + 다시 쓰기 1로 «소하천 범람» 하루를 끝까지 이었고, 9문 모두 SUCCESS였다. 처리 시간은 평균 146.9초(사슬 8단계 평균 134.5초), 최대 246.6초(YC-07·YC-07b), 최소 65.2초(YC-01)였다. 90초 안은 아침·특보 두 단계뿐이었고, 계획 연계(YC-07·07b)와 보고(YC-08)는 180초를 넘어 예열이 필수다. YC-07 은 짧게 다시 써도 246.6초 그대로였다. 근거 쪽은 답 글에 한 번도 나오지 않았다(0/9). 문서·계획 이름은 YC-02·YC-06·YC-08 에만 나왔다. 쪽은 자동 조회로만 붙일 수 있다: 힌남노 단계(YC-04·05·07·08) → «2022 재해연보» p.146, 2024-07-10 특보(YC-06) → «2024 재해연보» p.154. 가장 좋은 흐름은 YC-01(소하천 지구 4곳) → YC-02(그 읍면 저수지, 조건 입력) → YC-03(북안면으로 좁히니 지정 중 저수지는 대평지 1곳) → YC-04(대평지 방수로·명주리 573-1 제방이 2022년에 실제로 부서짐) → YC-08(용계리 소하천: 피해 최대인데 미지정·미반영 = 우선 점검)이다. 2022년 «당시 조치»는 T3Q 에 기록이 없다(특보 0, 문자 DB 2023-09-16부터). 대신 2024-07-10 홍수특보 시간표로 보인다. 「이어서 묻기」 꼴 비교는 한도 때문에 보내지 못했다.
