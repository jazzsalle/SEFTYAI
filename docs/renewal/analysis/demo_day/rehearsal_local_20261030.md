## 5. 함께 발견한 것

1. **「AI 모드 · 특보 자동 반영」 표기와 동작이 다르다.**
   - 표기: AI 모드를 켜면 특보 줄 단추가 이 글로 바뀐다. 말풍선(「AI 모드에서는 현재 특보가 질문에 자동으로 반영됩니다」)과 도움말(「켜져 있는 동안에는 현재 발효 중인 특보가 모든 질문에 자동으로 반영됩니다」)도 같은 말을 한다.
   - 동작: 실제로 특보가 붙는 것은 브리핑과 AI 모드 점검뿐이다. 직접 쓴 질문, 질문 모음, 시연 묶음에는 붙지 않는다(`app/src/app/(main)/explore/page.tsx` askText·askLib·askDemo).
   - 시연 묶음에 특보를 붙이지 않는 것은 대본 §8 #2 결정과 같다. 어긋난 것은 표기 쪽이다. → **표기를 동작에 맞춤**(R46, 사용자 결정 2026-10-30 — 단추 「AI 모드 · 브리핑에 특보 반영」).
2. **T3Q 데이터 글자 밀림**: 침수 사건 FE-8 의 이름이 「우20년07월 장마철 집중호」다(초량1지구). 무대 BS-04·BS-07 의 자동 조회 표와 답 표에 그대로 보인다(T3Q 요청 #30).
3. **질문 목록**: 리허설 화면은 질문 목록을 펼친 채였다(대본 §7.2 #4 는 접어 둠). 스크립트만의 차이다.
4. **하네스 버그(고침)**: 브리핑 네 항목을 동시에 보내 접수 응답 순서가 섞이면서, 파일 이름(BRF-BS-n)이 실제 항목과 어긋났다. 요청의 항목 번호(`briefing.item_no`)로 이름을 정하게 고치고, 이번 폴더도 바로잡았다.
