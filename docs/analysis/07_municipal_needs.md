## 2. 기관별 상세

### 2.1 부산광역시 (자연재난과)

**회의(7/29, 부산시청) 요지**
- 부산시는 기존 데이터와 실시간 데이터를 결합하는 재난대응 실증사업을 추진합니다. 이 실증사업이 본 사업 데이터를 API로 쓸 수 있는지 문의했고, 답은 "가능"입니다(NIA 표준화·공개 데이터). 다만 부산 전용 API를 새로 만들기는 어렵습니다.
- **최대 관심사는 1년 이후 지속 운영**입니다. 행안부 GPU 서버를 계속 활용하는 방안을 협의하기로 했습니다.
- 부산 풍수해 시스템(9/13 완료)에 **위험·조치 메시지를 우선 표출하는 API 연계**를 원합니다.
- 서비스 방향: 상황 입력(지역·시간당 강우량) → 주의보·특보 발령 판단 기준 + 유사 피해사례 제시. 위험지역은 하천·내수·자연재해로 나누어 자연재해저감종합계획과 연계합니다.
- 데이터 실태
  - 자연재해저감종합계획은 2018년본만 있습니다(2025년 최신본 요청).
  - NDMS에는 예산이 드는 피해 위주로 등록되어, 미등록 자료가 개인 PC에 흩어져 있거나 유실됐습니다.
  - CCTV는 약 1개월분만 보관합니다. IoT 수위·수문 시계열은 축적돼 있습니다. 부산안전ON에 OPEN API가 있습니다.

**AI에게 묻고 싶은 질문 (11건)** — 대부분 **"언제 조치하는가"** 와 **절차**에 관한 질문입니다.
1. 태풍 예비특보: 진로·강도가 비슷했던 최근 태풍과 당시 피해 규모는? (과거 사례)
2. 기상특보별 상황판단회의 실시 시점과 주재자별 참석자는? (절차 안내)
3. 호우주의보 직후: 급경사지·자연재해위험개선지구 중 먼저 점검할 곳과 지정 사유는? (위험지역 근거)
4. 비슷한 강수량·특보 상황에서 과거 지대본을 몇 단계로, 언제 가동했나? (과거 사례)
5. 위험기상 시 **재난문자를 언제 발송**하는지? (과거 사례/절차)
6. 위험기상 시 취약지역 주민을 **언제 대피**시키는지?
7. 지하차도·하상도로를 **언제 통제**하는지?
8. 온천천 산책로·하상도로의 최근 통제·해제 이력과 기준 수위는?
9. 대형 태풍 접근 시 이동자제·원격수업·차량대피 등 사전조치를 **체크리스트로** 정리해줘
10. 특보 해제 후 지대본 해제·상황관리 전환 절차와 **보고 양식**은?
11. 비슷한 규모의 호우 피해에서 특별재난지역 선포까지 걸린 기간과 절차는?

### 2.2 영천시 (안전재난하천과)

**회의(7/29, 영천시청) 요지**
- 업무 흐름은 **접수 → 현장확인 → 업체 조치 → 결과**입니다. NDMS 피해보고는 수일~4일 안에 입력하며, 피해 위주로 입력합니다.
- 재난 단계: **'경계' 단계에서 상황판단회의를 거쳐 부시장 주재로 재대본을 가동**합니다. 그 전 단계는 하천과가 담당·총괄하고, 최종 의사결정만 시장이 합니다.
- **실무 부담**
  - 담당자가 2년마다 바뀌어 매뉴얼 숙지가 어렵습니다.
  - **3~6시간마다 상황보고서를 반복 작성**합니다.
  - 이 두 가지가 고객이 말한 문제("신고를 받고서야 업무 시작")의 직접 원인입니다.
- 실증사업은 CCTV·IoT 실시간 데이터와 과거 데이터를 결합해 예측하는 사업입니다. 본 사업은 기준 데이터(수위 임계치 등)를 제공하는 역할을 합니다.
- 자료
  - 자연재해저감종합계획은 2016년본이며 갱신이 곧 끝납니다.
  - 하천·소하천기본계획은 **GIS Shape 원본**으로 받기로 했습니다.
  - 급경사지·산사태 주의구역(위치·사진, 수백 건)도 제공 가능합니다.
  - NDMS 보고서 양식과 내부 상황일지를 공유하기로 했습니다.

**질의 (2건)**
- 호우특보 발효 시: 실시간 강우현황을 바탕으로 **위험지역 우선순위** 확인
- 상황이 길어질 때: **상황별 대응 전략**을 제시할 수 있는가?

**업무현황**
- 먼저 확인하는 것: 기상특보, 강수현황, 하천 수위
- 판단 기준: 시간당 강우량, 하천 계획홍수위
- 유사사례 비교 기준: 강우량에 따른 피해유형별 비교
- 원하는 화면: 과거피해위치·저감계획·하천기본계획을 모두 겹쳐 보기

**요청 기능 (3건, 모두 '상')**
- AI 챗봇: 재해위험지구 피해 발생 시 **보고서화**
- AI 챗봇: 예측을 기반으로 한 **대응 전략 제시**
- 지도: 재해위험지구 + 소하천기본계획 겹쳐보기 (호우 시 우선 점검구역 선정용)

### 2.3 인제군 (안전교통과)

**회의(8/4, 인제군청) 요지**
- 인제군 실증사업(GIS 대시보드, NDMS 보고서 초안 AI, 급경사지 점 표출)과 기능이 비슷해서, 서로의 범위를 묻는 질문이 나왔습니다. 답변: 본 사업은 3개 지자체 공통 기능과 **질의 구조화(JSON 스키마)** 를 맡고, 실증사업자는 이를 연결해 쓰면 됩니다.
- 본 사업의 과업 대상은 **풍수해 5종(호우·침수·태풍·산사태·홍수)** 입니다. 폭염·대설은 제외지만 인제군은 대설 대응의 필요성을 제기했습니다. 과거 데이터 기준일은 2026.5.26이고, 실시간 API 연계는 없습니다(상황조건은 수동 입력).
- **실무 체감도**
  - 가장 높은 자료: **현장조치 행동매뉴얼**. 13개 협업반의 1~4단계 조치, 경보시설 위치·방송 절차가 들어 있습니다.
  - 실무와 맞지 않는 자료: 행안부 표준·광역 실무매뉴얼
  - 대응 상황에서 거의 쓰지 않는 자료: 자연재해저감종합계획·하천기본계획
- 유사사례 확인 방식: **재해대장 10년치**를 6개 읍면·시설별로 보고, 같은 장소에서 피해가 반복됐는지 판단합니다.
- 급경사지는 200개소라서 목록만으로는 판단할 수 없습니다. 자체적으로 정한 중점관리 대상을 반영해야 합니다.
- 기관 간 기준 차이 사례: 한강홍수통제소가 경고를 냈지만 현장 수위는 무릎 높이였습니다. 측정 시점의 지연과 기준 차이 때문입니다.
- 매뉴얼은 민간인 연락처를 삭제한 뒤 제공했습니다(본 분석에 쓴 '비상연락망 삭제본').

**질의 (11건)** — 6건은 예시 질의를 '적정함'으로 그대로 채택했습니다.
- 우리 관할 재해위험지구는 어디이고 왜 지정됐는가? (평시)
- 호우경보 직후: 과거 비슷한 호우 때 어디에서 어떤 피해가 있었는가?
- ○○천 주변에서 침수가 반복된 지점과 피해 규모는?
- 과거 유사사건은 어떻게 전개됐는가? (특보 변화 → 피해 → 통제 시점)
- 과거 유사 상황에서 **통제·대피를 언제** 했는가?
- 유사사례의 복구 소요기간과 지원내역은?
- 누적강수가 며칠째일 때 중점관리할 지역은?
- **즉시 대피가 필요할 때 필요한 조치(대피장소, 구호물품, 대피인력)는?**
- 향후 3시간 내 피해가 가장 우려되는 지점·경로는? (실증사업 영역)
- 인접 시군·산지에 강수가 전망될 때 피해가 가장 클 지역은? (실증사업 영역)
- **지점별 가용 인력·장비는?** (본 사업 데이터 범위 밖)

**요청 기능 (2건, 모두 '상')**
- AI 챗봇: 답변에 **근거 문서(페이지)** 를 함께 표시 — 내부 보고 때 출처를 밝혀야 하기 때문
- 지도: **캠핑·야영장 등 우려지역 현황** 대시보드 표출 — 계곡·하천 지역의 주요 인명피해 유형이기 때문

**지도 표시**: 산사태·급경사지, 대피시설, 과거 피해위치는 필수입니다. 하천·재해위험지구·침수흔적도는 후순위입니다.

## 3. 의견수렴 결과보고(8/27)의 핵심 해석

결과보고 p.8은 업무현황에서 다음 네 가지 문제를 도출했습니다.

| 문제 | 근거 발언 | 서비스 대응 (본 분석 데이터) |
|---|---|---|
| ① 정보가 흩어져 있다 | "재해위험지구와 소하천계획을 한 화면에서"(영천), "과거피해 + 위험지구"(부산), "하천계획 + 과거피해 + 산사태"(인제) | 지도 레이어 통합 (본 문서 범위 밖) |
| ② 근거를 다시 찾아야 한다 | 문서명·페이지 표시(부산), 근거문서 표시(영천), 근거·정확도 95%(인제) | `manual_procedures.json`의 모든 조치에 PDF 쪽번호 + `manual_images` 원문 이미지 |
| ③ **조치 시점을 알 수 없다** | "재난문자·주민대피·도로통제를 언제"(부산 질의 3·4·5), "통제·대피가 언제"(인제), "통제·해제 이력과 기준 수위"(부산) | **특보 단계별 task·timing·fieldActions.criteria**: 하천 진·출입은 예비특보 시 즉시 차단(부산 p.80), 온천천 30mm(p.119), 영천지하차도 15cm(p.289), 세월교는 호우경보 시(p.288), 인제 물놀이 지역 20mm/2h 40mm(p.58), CBS는 상황판단회의에서 결정(영천 p.45) |
| ④ 조치할 자원을 알 수 없다 | 대피장소·구호물품·인력(인제), 가용 인력·장비(인제) | 매뉴얼에 있는 범위만 제공: 인제 수방자재·중기연합회 장비 현황(p.94), 인명피해 우려지역 대피장소·수용인원(p.38–51). 실시간 보유현황은 범위 밖 |
