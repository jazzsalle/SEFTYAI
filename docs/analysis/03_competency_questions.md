## 4. CQ v1.1의 구 화면 ID (08_UI_화면설계, 참고)
CQ 엑셀은 `SCR-01~SCR-28`(좌측 조건/Agent · 중앙 지도 · 우측 답변·사례·근거 · 하단 검증추적)을 정의했으나, 이후 시연 HTML(261001)에서 **`SCR-UNE-xxxxxx` 체계로 대체**됨(01_requirements.md §2 참조). 대응: SCR-01 Header→공통 헤더 · SCR-02/03 조건입력·Active Context→SCR-UNE-101001/101002 · SCR-04/07 Agent→SCR-UNE-102001 · SCR-05/06 지도→SCR-UNE-103001 · SCR-08 유사사례→SCR-UNE-201002 · SCR-09 위험/계획→위험·취약/계획지식 상세 · SCR-10 근거→SCR-UNE-401001/401002 · SCR-13 사례비교·SCR-14 Timeline→SCR-UNE-301001/301003 · SCR-12/15/17/20~25 검증추적·내부검증 모드→운영관리 추적로그(SCR-UNE 미정)로 축소 · SCR-16 공개용 모드→폐기(민간 UI 미제공).

## 5. 부산·영천·인제 시범 데모 질문 Best 20

선정 기준: ① 지자체 의견수렴 공통 1~3순위(위험·취약지도, 과거 유사사례, 근거문서 동시 표시) ② 지역 특성(부산=도심 침수·지하차도, 영천=하천·소하천, 인제=산사태·급경사지·캠핑장) ③ CORE 또는 근거로 답 가능한 CONDITIONAL ④ 화면 흐름(목록→상세→지도→근거→후속질의)을 한 번씩 보여줄 것 ⑤ 8월 월간보고 지시: **계획문서 핵심질문(위험요인·제방고 등) 응답 품질 시연**.
