## 4. 주요 미결·확인 필요 사항 (구현 영향순)

1. **T3Q 회신 전무**: 2차 검토회신표 417건, 데이터 구축회신 327행, 기술협의서 T-01~T-25 회신란 모두 공란 → 응답 스키마·필드명 미확정(현재는 UNE 제안안). 프로젝트 가정: 전부 제공.
2. **공간정보 호출 경로**: v1.71 "T3Q Spatial API" vs 0917 요청서/pptx "아이타이쿤 ITK-xx 직접 조회/3사 협의" — 미확정.
3. **공개등급 코드**: 공통규약 3종(PUBLIC/INTERNAL/RESTRICTED) vs 재난메타 PRV-05 4종(공개/제한공개/내부전용/비공개) 대응 미확정. v1.71은 사용자 유형별 조회 제한 없음.
4. **대화 문맥 방식**(Stateful/Stateless, 만료시간 24h 예시 vs 보관 90일/1년) 미확정(T-02/T-03).
5. **브리핑**: 운영자 프리셋 vs 개인별 설정(최대 8) — '변경 협의'.
6. **FUN-UNE 기능분해도 원본 미보유**: 기능명은 HTML 주석 기반 추정. 위험·취약 상세·계획지식 상세·기상특보 화면 등 SCR ID `(미정)`.
7. **UFR-001-001 하위 ID 번호 불일치**(01 시트 vs 02 시트 DP-09/AI-01 참조).
8. **세션 만료 안내**(20초/60초 전, 30분 무활동)는 '내부 협의' 상태.
9. **행안부 계정**: v1.71은 행안부 담당자 유형 삭제, HTML FLOW에는 '행안부 계정·기본값 전국' 화면이 남아 있음 → 지자체 공무원 유형으로 통합 필요(전국 선택은 모두 가능).
